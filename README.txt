GymPlan PWA
Diese Dateien sind für eine installierbare Web-App vorbereitet.
WICHTIG: Installation auf Android benötigt eine HTTPS-Adresse (z.B. GitHub Pages).
index.html, manifest.webmanifest, sw.js und Icons gemeinsam hochladen.
Danach Website in Chrome öffnen > ⋮ > App installieren / Zum Startbildschirm hinzufügen.
Lokale HTML-Dateien allein können keine PWA installieren.
Backup aus deinem bisherigen GymPlan anschließend in der Web-App importieren.
